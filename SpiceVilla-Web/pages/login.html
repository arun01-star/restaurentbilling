Set up Google sign-in
  1. Open the Google Cloud Credentials page and select or create a project.
  2. Configure the OAuth consent screen, then create an OAuth client ID for a Web application.
  3. Add this authorized JavaScript origin: http://127.0.0.1:8000. No redirect URI is needed for this sign-in button.
  4. Copy the client ID into backend\.env as GOOGLE_CLIENT_ID=your-client-id, then restart SpiceVilla.

Only the public client ID belongs here. Never paste a client secret into the website or chat.

Customer accounts and orders require the SpiceVilla server. Guest browsing is available without signing in.
